## 🎯 Getting Started

### Navigate to Create Chart
- Click **"Create Chart"** from the landing page or header

### What You'll See
- **Smart Recommendations** banner (top) - AI suggests the best chart type
- **Quick Start** buttons (left) - Sample data and templates
- **Data Panel** (left) - Edit your data in a spreadsheet
- **Design Panel** (left) - Choose colors and chart type
- **Preview** (right) - Live chart preview

## 🎨 Create Your First Chart

### Method 1: Using Sample Data (Easiest)

1. Click **"Sample Data"** in Quick Start
2. Browse categories: Business, Analytics, Marketing, Finance, Health
3. Click on any dataset to load it
4. **Done!** Your chart is ready to customize
5. Try different chart types to see which looks best
6. Click **"Save"** to keep your chart

### Method 2: Using Templates

1. Click **"Templates"** in Quick Start
2. Select a category or view all
3. Choose a template (e.g., "Sales Dashboard", "Website Traffic")
4. **Done!** Template loads with sample data
5. Customize colors, styling, or data
6. Click **"Save"** when satisfied

### Method 3: From Scratch

1. Enter your **chart title**
2. Use the **Data Editor** to:
   - Add/remove rows (datasets)
   - Add/remove columns (labels)
   - Type values directly into cells
3. Select **chart type** (bar, line, area, pie, doughnut)
4. Choose a **color palette**
5. **Save** your chart

## ✨ Key Features

### 1. **Spreadsheet-Style Data Editor**
- Click any cell to edit
- **Add Column**: Add new data labels
- **Add Dataset**: Add new data series
- **Duplicate Row**: Copy a dataset
- **Remove**: Delete columns or rows
- **Real-time Preview**: Changes appear instantly

### 2. **Smart Recommendations**
- Automatically appears based on your data
- Shows best chart types with confidence scores
- Click any recommendation to apply
- Saves time and improves results

### 3. **Color Palettes**
- 20+ professional color schemes
- Categories: Business, Vibrant, Pastel, Monochrome, Colorblind-safe
- Click a palette to apply to all datasets
- Colors auto-assign to datasets

### 4. **Quick Actions Toolbar**
- **Save** (Ctrl+S): Store chart in gallery
- **Export**: Download as PNG or PDF
- **Duplicate**: Create a copy
- **Reset**: Start over
- **Undo/Redo** (Ctrl+Z / Ctrl+Y): Revert changes

### 5. **Advanced Styling** (Optional)
- Font family and size
- Border width and radius
- Line smoothness (for line/area charts)
- Toggle grid lines, legend, data labels
- Legend position (top, bottom, left, right)

## 💡 Tips & Tricks

### Keyboard Shortcuts
- **Ctrl + S**: Save chart
- **Ctrl + E**: Export chart
- **Ctrl + Z**: Undo
- **Ctrl + Y**: Redo

### Best Practices

1. **Start with Templates**: Use templates for common chart types
2. **Use Sample Data**: See how real data looks in charts
3. **Try Different Chart Types**: Switch between bar, line, area, pie, doughnut
4. **Color Matters**: Choose palettes appropriate for your audience
   - Business reports → Corporate/Modern palettes
   - Presentations → Vibrant/Tropical palettes
   - Accessibility → Colorblind-safe palettes
5. **Less is More**: Avoid too many datasets (max 5-7 for clarity)
6. **Label Clearly**: Use descriptive dataset labels

### Common Use Cases

- Chart Type: Bar
